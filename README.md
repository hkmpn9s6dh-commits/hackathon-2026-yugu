# 雨骨 · 一把记着二十五天雨的西湖绸伞

2026 年第二届 AI 工艺美术创意设计大赛（浙江省机电集团／浙江省工艺美术研究院）参赛作品。

## 一句话

杭州 2024 年的梅雨下了 25 天、422.8 毫米。这把西湖绸伞把这 25 天做成伞面上的一圈一圈墨：
**一天一圈，一滴墨一毫米**，从伞心排到伞边；收起来，它还是那支竹。

## 复验

```bash
npm ci
bash scripts/verify.sh      # 数据对账 → 字体 → 重出三张 → 300dpi → 说明四要素
```

`scripts/render.mjs` 是 fail-closed 的：字体没加载、文字溢出、出安全区、字号 <24px、
版面数字与 `data/rain-2024.json` 不一致——任一条不过就拒绝出图。

单张调试：`node scripts/render.mjs --only 01`

## 这份作品的三条规则（改任何东西之前先看）

1. **一天一圈**：25 天 → 25 圈，从伞心（6·09）到伞边（7·03）；每圈等面积（`r = R·√(i/25)`）。
2. **一滴墨 = 一毫米雨**：第 i 天画 `round(mm_i)` 滴，全伞 424 滴。
3. **一圈的墨色也由当天雨量决定**：不透明度 `0.03 + 0.38·(mm/max)^0.8`。

工艺侧的三个数字不许动：32 根骨（每根 4 毫米）、25 圈墨、80 厘米伞面 / 250 克。
