# 文化考据与出处（每条都能点开）

> 闸 A 要求：文化元素怎么变成具体的造型／纹饰／材质／使用方式，而不是"生成一幅带传统符号的画面"。
> 这一页是我做取舍前查过的原始材料。

| 淡竹取自安吉、富阳、余杭，三年以上，节间不小于 38 厘米；一把伞需 10–15 天 | 三联生活周刊《刀剑剪扇伞：工业与博物之间》 https://old.lifeweek.com.cn//2011/1208/36014.shtml |
| 收拢时绸面不外露，还原成一支淡雅圆竹，一手可握 | 杭州市档案馆「西湖绸伞」 https://www.hzarchives.org.cn/info/6939 |

**为什么落在这件器物上**：绸伞天生有两态——撑开是"面"，收拢是"骨"。它自己的工艺要求"收拢必须还原为一支竹"，这句话本身就是一句设计约束：任何加在伞面上的东西，都必须能被收进竹青里。所以墨只能落在绸上，不能加结构、不能加灯、不能加电子件。

## 三、把文化变成造型的三步

1. **选器物**：不选摆件、不选首饰，选"要用的东西"——伞是雨天要撑的，实用性有天然落点（官方四项里两项靠它）。
2. **选记什么**：不记西湖十景（已被刷花做尽），记一场真事。江南的雨是这个地域最公共的记忆，而 2024 年那场"暴力梅"有官方起止日、有逐日数据，可核对。
3. **选怎么记**：用伞自己的几何——32 根骨是角度，25 天是半径。骨数不动（工艺），天数进半径（记录）。两套数字各管一件事，不互相冒充。

## 四、刻意不做的三件事

- **不写书法、不盖名家印**：伞面上的字会抢走"记录"这件事；只留一方小印。
- **不画雨**（不画斜线雨丝）：雨量用"滴数 + 墨色"两个量表达，画雨丝就成了插图。
- **不加智能件**：官方公告明确"AI 是设计创作手段，不等于最终作品必须成为电子产品"。
