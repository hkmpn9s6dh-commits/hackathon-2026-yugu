# 07-UI：风格、尺子、记忆点、主屏规格

> 闸 A 的第三件东西。过闸之后这张纸就是施工的尺子：改版先看这里，不在这里的改动一律不做。

## 1. 风格预设（三选一，定死）

选 **「纸 · 墨 · 朱」**：宣纸底（#F7F2E6）、松烟墨（#1B1E1A）、朱砂（#9C2A22），竹青只作辅助（#8A7449）。

理由：这是一件"记在绸上的天气"，不是科技产品。纸墨朱是工美评审最熟的语汇，也是唯一能同时装下"伞面纹样"和"数据"的容器——图表放上去不突兀，纹样放上去不老气。

**反例库**（见到就改）：
- 冷白底 + 蓝紫渐变 + 玻璃拟态（像 SaaS 落地页）
- 深色底 + 霓虹光晕（像游戏宣发）
- 满版渐变彩虹／赛博纹样（AI 生成图最常见的味道）
- 三张都在讲"概念"，没有一张给尺寸、材料、工序

## 2. 尺子（往届得奖作，名单级 + 类型级）

官方公告未公开第一届作品图；可拿到的是同一主办体系（浙江省工艺美术研究院）2025 年 10 月「AI赋能工美，创意点亮生活」工艺美术 AI 创意设计大赛的**完整获奖名单**（54 件）。图拿不到，就用名单当尺子——它至少说明"什么样的作品会被这套评审选上"。

**一等奖 5 件**：《璧合·骏安》《祥辰十二图》《双童彩》系列、《唐风遗韵·南音传承——南音非遗馆品牌 IP 形象设计》《山水间》禅意灯。
**其余（抽样）**：《莫比乌斯-药酒包装设计》《青瓷时绽-青瓷时钟》系列、《脱胎大漆服饰》《十二生肖系列红木发梳》《裂光之诗》哥窑开片陶瓷灯具、《雷峰塔主题香薰夜灯系列摆件》《银竹苗韵·欢歌手袋》《良渚神人兽面芯片戒指盒》《青韵盏-青瓷香氛夜灯》系列。

从名单里读出的三条（这直接改了做法）：

1. **几乎全是"器物 + 使用场景"**：灯、香器、茶具、首饰、夜灯、摆件。纯图案、纯海报型投稿在这套评审里没有位置。
   → 所以这件作品不是"一张伞面纹样"，而是把"伞"当器物做完：尺寸、材料、工序、重量、收拢态。
2. **主流语汇是"传统工艺 + 现代功能"**：青瓷台灯、哥窑开片灯具、智能宫灯、香薰夜灯。
   → 我不加电子件（官方公告明确"AI 是设计手段，不等于作品必须成为电子产品"），但必须给出"它为什么会被用"——雨天撑、晴天挂、送人有话说。
3. **命名是"主名 + 副名"**：《裂光之诗》哥窑开片陶瓷灯具。题材偏本地文化（良渚、雷峰塔、瓯窑、畲族）。
   → 《雨骨》+「一把记着二十五天雨的伞」；题材取杭州 2024 年梅雨，本地、可核。

**这一场的尺子局限**：只有名单、没有图，做不到"把成品和得奖作混排盲排"。补救办法见 `proof/gate-d/README.md`（同题三版盲排，两位评委）。

## 3. 记忆点（只能有一个）

**一天一圈，一滴墨一毫米。**

伞面上 25 圈，是那场雨的 25 天；总共 424 滴墨，是 424 毫米雨。评委只要记住这一个换算，就记住了整件作品。

反面：不要说"AI 赋能传统工艺"（谁都这么说），不要说"东方美学与现代生活的对话"（等于没说）。

| 项 | 值 |
| --- | --- |
| 画布 | 3508 × 4961 px（A3 竖版 / 300dpi） |

| 版面元素 | 眉标 30px／标题 320px／竖排副标 46px／主句 96px／数据 92px + 标签 33px／注脚 30px |

| 最小字号 | 24 px（= 2.0 mm，再小印不清） |
| 颜色 | 纸 #F7F2E6／墨 #1B1E1A／朱 #9C2A22；墨圈不透明度 0.03–0.41（按雨量） |
| 数量 | 25 圈（等面积）、32 根骨、424 滴 |

## 5. 三张怎么分工（一张只干一件事）

| 张 | 干什么 | 让评委确认什么 |
| --- | --- | --- |
| 01 撑开 | 给第一眼 | 这是一把伞，也是一段记录 |
| 02 里面 | 给可信度 | 它按老法做得出来（骨、线、斗、18 道工序） |
| 03 收起来 | 给落地 | 收起来是一支竹；换个数据就是另一把伞 |

## 6. 施工护栏（写进 render.mjs，不过就拒绝出图）

1. 字体真加载（缺字会静默回落系统字体，字形全变）
2. `data-fit` 元素不溢出
3. `data-safe` 元素不出安全区
4. 所有文字 ≥ 24px
5. 版面数字与 `data/rain-2024.json` 一致（改数据不改版面会被拦下）
