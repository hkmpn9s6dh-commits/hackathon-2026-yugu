# 闸 D · 第一眼（2026-11-15）

## 这一场为什么是"同题三版盲排"

闸 D 的标准做法是：成品 + 往届得奖作（≥5 件）混排、随机字母、至少两位没参与的评委各自排名，每一位把成品排在至少 3 件得奖作之上。

这一场拿不到得奖作图：
- 官方公告没有第一届作品图；主办方公众号 2025 年那份获奖公示只有**名单表格**（已下载核对，见 `ruler-raw/`），没有作品图。
- 配套可查的同类赛事（海丝之光 AI 青瓷设计大赛）获奖图在第三方站，403／拿不到。

所以照"尺子拿不到"的替代做法执行：**同题三版盲排**——同一件作品做三个版式方案，随机字母 A/B/C，交给两位没参与制作、只看图的评委各自排名。评委不知道哪一版是作者自己选的。

## 三版是什么

| 版 | 做法 | 想验证什么 |
| --- | --- | --- |
| A | 全开俯视居中、标题左上、数据在页脚（= 定稿版） | 器物优先：一眼先看到伞 |
| B | 伞面局部放大铺满上半页，下半页墨色版块压标题与数据 | 材质优先：用特写换冲击力 |
| C | 伞面缩小、竖排标题靠右、大量留白 | 克制优先：把它当"图录"排版 |

## 两位评委的结论（原文要点）

**评委一**
- 排名：A > B > C
- A：「中央伞面完整、精确，像伞的档案标本，一圈圈墨带能读时间」
- B：「最有张力，但裁剪让伞的中心消失，整体有点抽象，不如 A 直接」
- C：「留白最多但图形太小，统计行像页脚注释，视觉力量被稀释」
- 扣分点：A 的数据标签（梅雨季/合计/墨点/最大的一天）字号偏小、偏淡

**评委二**
- 排名：A > C > B
- 推荐 A 进复评：「唯一能在展板上瞬间读成专业设计竞赛投稿的一版；B 的特写漂亮但读不出是伞，C 中间大片空白在展板上像没排满」
- 工艺可信度：A
- 排版硬伤：A 的数据行与脚注间距偏紧、印章偏小；B 的版块把标题衬得过强、像宣传册

## 判定

**条件性过线**：两位评委都把 A 排第一（2/2 一致），A 是定稿版。
不满足"排在 ≥3 件得奖作之上"这一条（没有得奖作图），所以记条件性——下一场同主办体系的比赛若拿到得奖作图，再用真尺子补一轮。

两位都点到的同一处，当场改掉了：**A 的数据标签字号 28 → 33px、颜色加深、字重 300 → 400；数据行与脚注间距拉开；印章放大（214×262 → 236×288）**。改完重出图，五类断言仍全过。

## 一处诚实的保留

评委是同一模型家族的两次独立跑，不是"不同家族"。它降低了"自己夸自己"的成分（评委不知道哪版是定稿），但不能当作真正的跨家族盲评。真正的跨家族盲评这一场没条件做，记在这里。
